> **人間観察（renjian-guancha）** —— 「人文の心」を軸にしたライティングスキル。

これまで公開してきた作品の中で、**初めて「道具感」ではなく「人文感」を軸に据えた**スキルです。
それ以前のスキルは「もっと速く、もっと安定して、もっと再利用しやすく」を解決してきました。この作品からは、**「どう痛みに寄り添い、対岸の人ではなく渡し守になるか」**を解決し始めます。

**これはマイルストーンです。**

---

## その価値

がんと闘う家族は、現実にあまりにも長く押しつぶされてきました——経済的に、情報的に、悲しみに、介護に。足りないのはさらなる理屈ではなく、**「見てもらえること」**です。

このスキルがすること。それは**観察**と**静かな表現**を通して：

- がん家族の悲しみを**受け止める**——避けず、飾らず、まず感情を受け取る；
- そこにある苦しみを**認める**——「前向きに」と言うのではなく、それが現実だと認める；
- それからやっと、そっと指し示す——**希望はどこに、陽だまりはどこに**；
- 最終的に、**内側から光る力**と**支え合い**を励ます。

スローガンを叫ばず、安易に和解させず、上から裁かない。**現実の苦しみを冷静に書き、対比で光を通す。**

## その姿勢（魂——譲れないもの）

1. **冷静な第三者の立場** —— 常に傍観者：肩入れせず、裁かず、当事者になりきらない。
2. **リアリティ優先、「悲惨」から目を逸らさない** —— 現実のほとんどはもともと重く、苦く、無力だ。ありのままに描く。飾らず、スープも飲ませない。
3. **着地点は「前向きなエネルギー」に寄る** —— ただしスローガン式の楽観ではなく、**冷色の中にひとすじの暖かさを残す**。
4. **「対比」で最も真実の感情を運ぶ** —— 生と死、冷たさと暖かさ、不条理と思いやり、失ったものと残っているものを並置して、感情が初めて地に足がつく。

> **「デザート」の技法**：人生の素の味は苦い。だから甘さが要る。**苦さを書き尽くしたら、必ずひとくちの「甘さ」を添える**——
> 具体的で小さなぬくもりを（ひとくちのケーキ、音程のずれた歌の部屋、子どもが描いたゆがんだろうそく）。泣く。「良くなるよ」と叫ぶのではなく、**甘さが見えるようにする**。

鋭さの向かう先は**「構造」**（インセンティブ、情報格差、制度の隙間）であり、特定の「悪人」や職業ではない。

## 何を生み出すか

複雑なテーマ（医療 / 生と死 / 介護 / 経済 / 恋愛と結婚 / 人間模様）を、**冷静＋人文＋文芸＋独立**の観察記事に書く。

| 成果物 | 説明 |
|---|---|
| **文字版**（デフォルト） | 手作業で仕上げた **HTML 1 ページ＋WeChat 縦長画像**（幅 1080px PNG）。普通の返信ではない |
| **挿絵版** | 文字版＋手描きイラスト 2〜3 枚を同じページに合成して縦長画像に |
| **テンプレートシリーズ** | 「橙暖愛」などの名前つきプリセット：一度の呼び出しで同じ見た目を再現 |

**トリガー**：`一篇書いて / 観察して / あなたの思い / この現象について / 気持ちを書いて`；
挿絵版はさらに `挿絵版 / 画像つき / 図を足して`。
**不向き**：ニュース速報、マーケティング記事、事実の要約、クイック Q&A、純データレポート。

## 構成

```
renjian-guancha/
├── SKILL.md                     # スキル本体（口調 / 骨格 / 納品 / 赤線 / 自己点検）
├── README.md                    # このファイル
├── CONTRIBUTING.md              # 貢献ガイド（新スタイルシリーズ / 絵本；AIエージェント向け手順つき）
├── assets/
│   ├── skeleton.html            # 起点となる HTML スケルトン
│   └── gallery/                 # シリーズごとの絵本（例：gallery/橙暖愛/）
├── references/
│   ├── themes.md                # テーマライブラリ：配色 / フォント / レイアウトトークン
│   ├── pipeline.md              # 画像・送信パイプライン（HTML → PNG → WeChat）
│   ├── illustration.md          # 挿絵版の全文（スタイル選択 / 挿入位置 / プロンプト / 検証）
│   └── templates/               # 再利用可能なテンプレートシリーズ（templates.json + <シリーズ>.md）
├── scripts/
│   ├── ensure_deps.sh           # 依存関係チェック / インストール
│   ├── illustrate.py            # 画像生成（複数バックエンド自動フォールバック）
│   └── preset.py                # シリーズ組立 / 直接出力
└── vendor/
    └── handraw-style-data/      # 同梱の手描き風スタイルデータ（handraw-style 未導入時のフォールバック）
```

## クイックスタート

```bash
# 依存関係チェック（初回 / 端末変更時）
bash ~/.agents/skills/renjian-guancha/scripts/ensure_deps.sh
```

アシスタントにこう言うだけ：**「一篇書いて：……」**（テーマは具体的に。あるいは観察に任せる）。デフォルトは文字版。絵が欲しければ **「挿絵版」** と言う。

## みんなで長く書き続ける

このプロジェクトのいちばん良い部分は、より多くの人に引き継がれるべきだ。

**PR を歓迎します。AI コラボレーターも歓迎します。** あなたの貢献は、あなたの名前と文采と表現とともに、ここに残り、
同時に使われていく——次の家族に読まれ、次の作品に受け継がれ、希望を灯していく。

- **PR 歓迎** —— **スタイルテンプレートシリーズ**、**人文絵本**の追加、あるいはたった一行をよりふさわしい言葉に直すこと。
- **AI コラボレーター歓迎** —— [`CONTRIBUTING.md`](CONTRIBUTING.md) には **「AI エージェント向けの曖昧さのない 12 ステップ」** がある：
  どんなエージェントでもそれに従えば、新しいスタイルシリーズを作り、新しい絵本を描ける。**これは意図的な設計だ。**
- 公開済み：**橙暖愛**（癒しの暖色 · 苦みの中から光る）、絵本は [`assets/gallery/橙暖愛/`](assets/gallery/橙暖愛/)。
  新しいシリーズが欲しい？ `CONTRIBUTING.md` に沿って加えればいい。

着手の前に、`CONTRIBUTING.md` の **3 つの赤線**に目を通すこと：実名での告発をしない、結論を下さない、挿絵に文字や印章を入れない。
