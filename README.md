> **人间观察（renjian-guancha）** —— 一个以「人文感」为中心的写作技能。

这是我发布过的所有作品里，**第一个不再以「工具感」为中心、而是以「人文感」为中心**的技能。
在此之前，技能解决的是「怎么更快、更稳、更可复用」；从这一件起，它开始解决**「如何能够感同身受，做引渡人，而不是对岸的人」**。

**这是一个里程碑。**

---

## 它的价值

肿瘤家庭被现实压着走了太久——经济的、信息的、哀伤的、照护的。他们不缺更多道理，缺的是**被看见**。

这个技能做的事，是通过**观察**和**冷静的表达**：

- **托住**肿瘤家庭的哀伤——不绕开、不粉饰，先接住情绪；
- **认可**其中的苦难——承认它真实存在，而不是劝人「想开点」；
- 然后才轻轻指出——**希望何在，暖阳何在**；
- 最终鼓励**内在的自我发光**，与**彼此的支持**。

不喊口号，不廉价和解，不站在高处宣判。**冷静地写现实的苦，再用对比，让光透进来。**

## 它的态度（魂，不可退让）

1. **冷静的第三方立场** —— 始终是旁观者：不站队、不宣判、不代入当事人的立场。
2. **现实感优先，且不回避「悲催」** —— 大部分现实本来就是沉的、苦的、无奈的。如实呈现，不粉饰、不鸡汤。
3. **落点偏向「正能量」** —— 但不是喊口号式的乐观，而是**在冷色里，留一点暖**。
4. **用「对比」承载最真实的情感** —— 生与死、冷与暖、荒诞与温情、失去与尚存并置，情感才真正落地。

> **「甜点」手法**：生活本味是苦，所以需要甜。**苦写足之后，务必补一口「甜」**——
> 一个具体的、微小的暖（一口蛋糕、一屋子跑调的歌、孩子画的歪蜡烛）。不是喊「会好的」，是**让甜被看见**。

把锋芒对准**「结构」**（激励、信息差、制度缝隙），而不是某个「坏人」或某个职业。

## 它产出什么

把复杂议题（医疗 / 生死 / 照护 / 经济 / 婚恋 / 众生相）写成 **冷静 + 人文 + 文艺 + 独立** 的观察文章。

| 产出 | 说明 |
|---|---|
| **文字版**（默认） | 手工精雕的 **HTML 一页 + 微信长图**（1080 宽 PNG），不是一段普通回复 |
| **插图版** | 文字版 + 2–3 张手绘插画，并进同一页出长图 |
| **模板系列** | 「橙暖爱」等具名预设：一次调用即复现同一观感 |

**触发**：`写一篇 / 观察一下 / 你的心得 / 就这个现象谈谈 / 写写你的感受`；
插图版再说 `插图版 / 配图版 / 加上图`。
**不用于**：新闻播报、营销软文、事实摘要、快速问答、纯数据报告。

## 目录

```
renjian-guancha/
├── SKILL.md                     # 技能主文件（语气 / 骨架 / 交付 / 红线 / 自检）
├── README.md                    # 本文件
├── CONTRIBUTING.md              # 贡献指南（新增风格系列 / 绘本；含「给 AI 协作者」步骤）
├── assets/
│   ├── skeleton.html            # 起始 HTML 骨架
│   └── gallery/                 # 各系列插图绘本（如 gallery/橙暖爱/）
├── references/
│   ├── themes.md                # 主题库：配色 / 字体 / 版式 token
│   ├── pipeline.md              # 出图与发送管线（HTML → PNG → 微信）
│   ├── illustration.md          # 插图版全文（选风格 / 插点 / 提示词 / 核验）
│   └── templates/               # 可复用模板系列（templates.json + <系列>.md）
├── scripts/
│   ├── ensure_deps.sh           # 依赖自检 / 安装
│   ├── illustrate.py            # 出图（多后端自动回退）
│   └── preset.py                # 模板系列组装 / 直接出图
└── vendor/
    └── handraw-style-data/      # 内置精简手绘风格数据（未装 handraw-style 时回落）
```

## 快速开始

```bash
# 依赖自检（第一次用 / 换机时）
bash ~/.agents/skills/renjian-guancha/scripts/ensure_deps.sh
```

直接对助手说：**「写一篇：……」**（题足够具体，或让它自己观察），默认走「文字版」；想要配图就说 **「插图版」**。

## 一起把它写长

这个项目最好的部分，应该由更多人接着写。

**欢迎 PR，欢迎 AI 协作者。** 你的贡献，和你的名字、文采与表达，一起留在这里，
同时被应用——被下一个家庭读到，被下一篇作品接住，点亮希望。

- **欢迎 PR** —— 新增一个**风格模版系列**、一本**人文绘本**，或者只是改了一行更妥帖的字。
- **欢迎 AI 协作者** —— [`CONTRIBUTING.md`](CONTRIBUTING.md) 里写了**「给 AI agent 的无歧义 12 步」**：
  任何 agent 都能照着它，自己造出一个新的风格系列、画出一组新的绘本。**这是有意为之。**
- 目前已发布：**橙暖爱**（治愈暖调 · 苦里透光），绘本见 [`assets/gallery/橙暖爱/`](assets/gallery/橙暖爱/)。
  想要新的系列？照着 `CONTRIBUTING.md` 加一个就是。

动手前请先看一眼 `CONTRIBUTING.md` 里的**三条底线**：不点名指控、不下定论、插画无字无印章。
