> **Жэньцзяньши (renjian-guancha, «Наблюдая за миром людей»)** — навык письма, в центре которого — человечность.

Из всего, что я публиковал, это **первый навык, построенный не вокруг «ощущения инструмента», а вокруг человечности**.
До него навыки решали задачу «как быстрее, надёжнее и воспроизводимее»; этот начинает решать **«как по-настоящему сопереживать — быть паромщиком через реку, а не чужаком на том берегу»**.

**Это веха.**

---

## В чём его ценность

Семьи, столкнувшиеся с онкологией, слишком долго придавлены реальностью — деньгами, нехваткой информации, горем, уходом за близкими. Им не хватает не советов, а того, чтобы **их увидели**.

Что делает этот навык — через **наблюдение** и **сдержанную речь**:

- **Поддержать** горе онкологических семей — не обходя его и не подкрашивая, сначала приняв эмоцию;
- **Признать** их страдания — признав, что они реальны, а не предлагая «просто не унывать»;
- И лишь затем тихо указать — **где надежда, где тёплый свет**;
- И наконец вдохновить на **внутреннее свечение** и **взаимную поддержку**.

Никаких лозунгов, никакого дешёвого примирения, никаких приговоров сверху. **Спокойно писать горечь реальности — и контрастом впустить свет.**

## Его позиция (душа — не подлежит компромиссу)

1. **Хладнокровная позиция третьего лица** — всегда наблюдатель: ни на чью сторону, ни приговоров, ни перевоплощений.
2. **Реальность прежде всего, без ухода от «тяжёлого»** — реальность по большей части и есть тяжёлая, горькая, безысходная. Показывать как есть: без глянца и без «вселюбовного позитивчика».
3. **Точка приземления — светлая** — но не лозунговый оптимизм, а **в холодных тонах оставить каплю тепла**.
4. **Контраст несёт самые честные эмоции** — жизнь и смерть, холод и тепло, абсурд и нежность, утрата и то, что осталось, рядом; только тогда чувство по-настоящему землисто.

> **Приём «десерт»**: простой вкус жизни — горький, потому и нужно сладкое. **Дописав горечь до конца, обязательно добавь глоток «сладкого»** —
> конкретное, крошечное тепло (кусок торта, комната поющих мимо нот, кривая свеча, нарисованная ребёнком). Не выкрикивать «всё наладится», а **дать сладости быть увиденной**.

Остриё направлять на **«структуры»** (стимулы, информационные разрывы, щели в институтах), а не на «злодея» или профессию.

## Что он создаёт

Превращает сложные темы (медицина / жизнь и смерть / уход / экономика / любовь и брак / портреты людей) в тексты наблюдения — **сдержанные + человечные + литературные + независимые**.

| Результат | Описание |
|---|---|
| **Текстовая версия** (по умолчанию) | Ручной работы **страница HTML + длинное изображение для WeChat** (PNG шириной 1080), а не обычный ответ |
| **Иллюстрированная версия** | Текстовая версия + 2–3 рисованные иллюстрации, собранные в то же длинное изображение |
| **Серии шаблонов** | Именованные пресеты вроде «Оранжевого тепла»: один вызов — тот же облик |

**Триггеры**: `напиши текст / понаблюдай / твои мысли / расскажи об этом явлении / опиши свои чувства`;
для иллюстраций добавьте `с иллюстрациями / с картинками / добавь рисунки`.
**Не предназначен для**: новостных сводок, маркетинга, пересказа фактов, быстрых ответов, чисто табличных отчётов.

## Структура

```
renjian-guancha/
├── SKILL.md                     # Главный файл навыка (тон / каркас / поставка / красные линии / самопроверка)
├── README.md                    # Этот файл
├── CONTRIBUTING.md              # Гайд по вкладу (новые серии стилей / альбомы; шаги для AI-агентов)
├── assets/
│   ├── skeleton.html            # Стартовый HTML-каркас
│   └── gallery/                 # Иллюстрированные альбомы по сериям (напр. gallery/橙暖爱/)
├── references/
│   ├── themes.md                # Библиотека тем: палитра / шрифты / токены вёрстки
│   ├── pipeline.md              # Конвейер картинок и отправки (HTML → PNG → WeChat)
│   ├── illustration.md          # Иллюстрированная версия целиком (выбор стиля / вставка / промпты / проверка)
│   └── templates/               # Многоразовые серии шаблонов (templates.json + <серия>.md)
├── scripts/
│   ├── ensure_deps.sh           # Проверка / установка зависимостей
│   ├── illustrate.py            # Генерация картинок (несколько бэкендов с откатом)
│   └── preset.py                # Сборка серии / прямая генерация
└── vendor/
    └── handraw-style-data/      # Встроенные урезанные данные рисованного стиля (фолбэк без handraw-style)
```

## Быстрый старт

```bash
# Проверка зависимостей (первый запуск / новая машина)
bash ~/.agents/skills/renjian-guancha/scripts/ensure_deps.sh
```

Просто скажите ассистенту: **«Напиши текст: …»** (тема конкретная — или пусть понаблюдает сам). По умолчанию — текстовая версия; для картинок скажите **«с иллюстрациями»**.

## Пишем это длиннее — вместе

Лучшая часть этого проекта должна продолжаться большим числом людей.

**PR приветствуются — соавторы-AI приветствуются.** Ваш вклад, вместе с вашим именем, слогом и голосом, остаётся здесь
и одновременно применяется — его читает следующая семья, его подхватывает следующая работа, зажигая надежду.

- **PR приветствуются** — добавить **серию стилевых шаблонов**, **иллюстрированный альбом** или просто переписать одну строку точнее.
- **AI-соавторы приветствуются** — в [`CONTRIBUTING.md`](CONTRIBUTING.md) есть **«12 однозначных шагов для AI-агентов»**:
  любой агент может пройти их и создать новую серию стилей, нарисовать новый альбом. **Это сделано намеренно.**
- Опубликовано: **«Оранжевое тепло»** (целительные тёплые тона · свет сквозь горечь), альбом в [`assets/gallery/橙暖爱/`](assets/gallery/橙暖爱/).
  Нужна новая серия? Просто добавьте её по `CONTRIBUTING.md`.

Перед началом прочитайте **три красные линии** в `CONTRIBUTING.md`: без обвинений поимённо, без окончательных приговоров, без надписей и печатей на иллюстрациях.
