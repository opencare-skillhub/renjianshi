# 模板系列 · 橙暖爱

> **一句话**：治愈暖调，苦里透光。适合"母女 / 陪伴 / 医患照料 / 病房里的暖"这类题材。

## 定向
- **情绪**：温暖、治愈、安静、有希望。冷静地写现实的苦，再用暖光让"甜"被看见。
- **对比**：冷色只留一点点（佩恩灰/石板灰）点住"苦"，主调永远是橙暖阳光。
- **尺度**：落在"照料与尊重"上——俯身、蹲下、平视、并肩、牵手；不煽情、不口号。

## 手绘风格
- 风格：**#196 油画棒治愈手绘**（Oil-Pastel Healing Illustration）
- 特征：粗颗粒、蜡质色块、奶油高饱和、拙朴人物、笔触温暖松软
- 主题色：**柿子橙 (C-26 Persimmon Orange) + 那不勒斯黄 (C-27 Naples Yellow)**

## 出图
```bash

PY=.venv/bin/python
$PY scripts/preset.py --template 橙暖爱 --scene "…" --run --out /abs/01-x.png
```
